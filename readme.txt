Hide the WordPress admin bar on your website for all users or for specific user roles. Lightweight, no setup needed.

== Description ==

**Hide Admin Bar** is the simple way to **hide the WordPress admin bar** (also called the toolbar) on the frontend of your website. Activate it and the admin bar is gone for everyone. Want to keep it for some users? Pick the user roles under *Settings → Hide Admin Bar*.

== Why choose Hide Admin Bar? ==

= ✨ Works right away =
Activate the plugin and the admin bar is hidden on your website for all logged-in users. No setup needed.

= 👥 Hide it per user role =
Hide the admin bar only for subscribers, customers or any other user role, and keep it for administrators and editors.

= ⚡ Lightweight =
No scripts or styles are added to your website. The plugin simply tells WordPress not to show the admin bar.

= 🧱 Works with any theme =
Use it with any theme, page builder, WooCommerce or membership plugin.

== How to use ==

1. Activate the plugin. The admin bar is now hidden on your website for all users.
2. To hide it only for some users, go to *Settings → Hide Admin Bar*.
3. Uncheck *All users* and check the user roles that shouldn't see the admin bar.
4. Click *Save Changes*.

== Installation ==
1. In your WordPress admin, go to *Plugins → Add New Plugin* and search for "Hide Admin Bar".
2. Click *Install Now*, then *Activate*.
3. Optional: go to *Settings → Hide Admin Bar* to hide the admin bar only for specific user roles.

== Frequently Asked Questions ==

= How do I hide the admin bar for all users except administrators? =
Go to *Settings → Hide Admin Bar*, uncheck *All users*, check every role except *Administrator* and click *Save Changes*.

= Does it hide the admin bar in the WordPress dashboard too? =
No. The plugin hides the admin bar on the frontend of your website. WordPress always shows it inside the dashboard.

= How do I show the admin bar again? =
Uncheck all roles under *Settings → Hide Admin Bar* and save, or deactivate the plugin.

= Can a user still turn the admin bar on in their profile? =
No. For the selected roles the admin bar stays hidden, no matter what's set under *Users → Profile → Toolbar*.

= Are my settings deleted when I delete the plugin? =
Yes. Deleting the plugin removes its settings. Deactivating it keeps them.
